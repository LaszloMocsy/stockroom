# Security Policy

## Supported versions

Stockroom has no stable release yet. Once releases begin, security fixes will be provided for the latest minor version.

## Reporting a vulnerability

> [!CAUTION]
>
> Please **do not** report security vulnerabilities in public issues, discussions, or pull requests.

Report them privately using GitHub's "Report a vulnerability" feature on the repository's **Security** tab (private vulnerability reporting).

Please include:

- A description of the issue and its impact.
- Steps to reproduce, or a proof of concept.
- The affected version or commit.

You can expect an acknowledgement within a few days. Please give us a reasonable time to fix the issue before any public disclosure.

## Scope

In scope: the Stockroom API, web app, mobile app, and the published Docker images and deployment examples.

Out of scope: vulnerabilities in third-party services you deploy alongside Stockroom (your reverse proxy, hosting platform, or database), and issues that require physical access to an unlocked device.
